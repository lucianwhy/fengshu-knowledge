## 当前限额

| 项目 | 默认阿里云入口 |
| --- | --- |
| 识别方式 | 出口 IPv4 地址；IPv6 以 /64 网段合并 |
| 每 IP 每日查询 | 30 次；单查询 1 次，多角度查询按实际查询数计 2～3 次 |
| 每 IP 每日阅读 | 100 次；包括原文分页与上下文读取 |
| 每 IP 短时频率 | 每分钟 6 次工具调用，含额度查询 |
| 全站检索上限 | 每日 500 次，每月 10,000 次 |
| 全站阅读上限 | 每日 2,000 次 |
| 重置时间 | 北京时间零点；月度额度在每月一日零点恢复 |

同一个出口 IP 的所有 Agent 共用额度。更换 Agent 名称、User-Agent 或 MCP 客户端不会获得新额度；服务不信任客户端自行填写的身份或转发 IP。受信任的 nginx 使用原始连接地址转发，服务只接受本机代理提供的地址。

**IP 不是自然人身份。** 多个人共享公司、家庭或云平台出口时，可能共同使用一份额度；换网络、代理或公网 IP，也可能获得不同额度。IPv6 /64 合并可减少临时地址轮换造成的重复发放，但不能阻止换网络。全站上限始终共同生效。

数据库保存带服务私密密钥的 IP 摘要，而不是原始 IP。个人／全站计数在 SQLite 事务中一并检查、扣减，再执行检索或阅读；失败的已受理请求也保留计数。握手和工具列表不消耗检索额度。
