# 常见思考角度

以下是原 Skill 的整理者对材料的概括，可作为检索线索和提问方式，不是作者的完整思想体系。涉及作者观点或引述时，请回到文章核实。

| 角度 | 可以追问的问题 | 使用时留意 |
| --- | --- | --- |
| 信息不对称 | 谁掌握了哪些信息？谁承担决策后果？ | 信息差只是解释之一，也要考虑能力、制度与运气。 |
| 代理关系 | 委托人和执行者的利益是否一致？怎样验证结果？ | 不要把所有合作都解释为算计。 |
| 树与路 | 是在积累零散知识，还是走通一条实际路径？ | 理论和实践可以相互促进。 |
| 终局倒推 | 目标是什么？今天的选择会影响哪些长期结果？ | 目标会变化，终局判断也可能出错。 |
| 糖果与糖纸 | 真正想要的是什么？哪些只是外在指标？ | 外在指标有时也是实际门槛。 |
| 不纠缠 | 哪些分歧会改变结果，哪些可以先放下？ | 重要的风险和基本质量不能忽略。 |
| 换一个观察层次 | 拉长时间、改变参与者或系统边界后，判断会怎样变化？ | 抽象视角需要回到可验证的事实。 |
